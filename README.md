# Student Grade Tracker

## About
A Java console-based application to manage student grades.

## Features
- Add students
- View all students
- Search by roll number
- Delete student records
- Calculate average, highest and lowest marks
- Class summary

## Technologies
- Java
- OOP
- ArrayList
- Scanner

## How to Run
Compile and run StudentGradeTracker.java using IntelliJ IDEA or the Java compiler.
